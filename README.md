# Astro Star India — refreshed static recreation

This build keeps the supplied site content/themes but removes navigation clutter and refreshes the visual system around the screenshot direction: deep wine + antique gold, warm paper cards, clearer hierarchy, responsive layout, and stronger image-led sections.

## Run

```bash
python -m http.server 8080
```

Open `http://localhost:8080/`.

### Notes
- The contact/consultancy forms are frontend demo forms; connect a backend or form service for real submissions.
- `political-astrology.html` is retained as a legacy source page but is intentionally removed from the main navigation because it was not part of the main visual journey.
- Images in `assets/` include screenshot-derived visuals plus original SVG illustrations created for this recreation.
